## Any mode

### Viewport navigation

`HOME` = Centre all objects

`Numpad .` = Centre selected object/vertices/whatever in the viewport

`Numpad 0` = Look through camera

`Numpad 1` = Front view

`Numpad 3` = Right view

`Numpad 7` = Top view

`Numpad 9` = Opposite of current view (e.g. if in `top`, flips to `bottom`)

`Numpad 2` = Rotate view down

`Numpad 8` = Rotate view up

`Numpad 4` = Rotate view left

`Numpad 6` = Rotate view right

`Numpad 5` = Toggle orthographic projection

### Transforming stuff

`g` = Move selected

`g + [x/y/z] + [number(s)]` = Move [along axis] by [number(s)] amount

`r` = Rotate selected

`r + [x/y/z] + [number(s)]` = Rotate [along axis] by [number(s)] amount

`s` = Scale selected

`s + [x/y/z] + [number(s)]` = Scale [along axis] by [number(s)] amount

`Tab` = Toggle Edit Mode

## Edit mode

`1` = Vertex select

`2` = Edge select

`3` = Face select

`E` = Extrude

## Texture painting

`SHIFT+X` (without click) = colour picker

`SHIFT+X+click` = add colour to palette
