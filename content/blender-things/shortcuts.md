## Any mode

### Viewport navigation

`HOME` = Centre all objects

`Numpad`

`.` = Centre selected object/vertices/whatever in the viewport

`0` = Look through camera

`1` = Front view

`3` = Right view

`7` = Top view

`9` = Opposite of current view (e.g. if in `top`, flips to `bottom`)

`2` = Rotate view down

`8` = Rotate view up

`4` = Rotate view left

`6` = Rotate view right

`5` = Toggle orthographic projection

### Transforming stuff

`g` = Move selected

`g + [x/y/z] + [number(s)]` = Move [along axis] by [number(s)] amount

`r` = Rotate selected

`r + [x/y/z] + [number(s)]` = Rotate [along axis] by [number(s)] amount

`s` = Scale selected

`s + [x/y/z] + [number(s)]` = Scale [along axis] by [number(s)] amount

`Tab` = Toggle Edit Mode

## Edit mode

`1` = Vertex select

`2` = Edge select

`3` = Face select

`E` = Extrude

## Texture painting

`SHIFT+X` (without click) = colour picker

`SHIFT+X+click` = add colour to palette
